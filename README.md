# OOP
## Описание
### Это проект, где я изучаю ООП

## Установка

### Сначала установим poetry
```pip install poetry```

### Установите зависимости
```poetry install```

## Документация
### src - пакет, содержащий модули кода
```main.py``` - модуль с основным кодом

```read_json.py``` - модуль для создания объектов из json файла

```category_iter.py``` - модуль для получения итератора продуктов из категории

```classes.py``` - модуль с классами Product и Category

```lawngrass.py``` - модуль с классом LawnGrass

```mixin.py``` - модуль с классом-mixin Mixin

```smartphone.py``` - модуль с классом Smartphone
### tests - пакет, содержащий модули тестирования кода
```conftest.py``` - модуль, содержащий фикстуры 

```test_category.py``` - модуль для тестирования методов класса Category

```test_product.py``` - модуль для тестирования методов класса Product

```test_categoryIter.py``` - модуль для тестирования класса-итератора categoryIter

```test_lawn_grass``` - модуль для тестирования методов класса LawnGrass

```test_smartphone``` - модуль для тестирования методов класса Smartphone

```test_mixin``` - модуль для тестирования методов класса Smartphone
